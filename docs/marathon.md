# Марафон (картка 8.4)

Безкоштовний денний курс з математики. Окремо від лідерборду `/leaderboard`: той лишається `marathons.kind = 'leaderboard'`. Денний курс — `kind = 'daily'`.

## Маршрути

| Шлях | Хто |
| --- | --- |
| `/marathon/[slug]` | Публічний лендінг: загадки і кнопка «Долучитися». Загадки не закривають доступ. |
| `/marathon/[slug]/join` | Реєстрація: ім’я, пошта, пароль. UTM з рекламного лінка зберігаються в `marathon_participants.source`. |
| `/marathon/[slug]/map` | Карта днів. Потрібна сесія і рядок учасника. |
| `/marathon/[slug]/day/[n]` | Матеріали, потім завдання. Закритий день не віддає матеріали й завдання. |
| `/marathon/[slug]/final` | Підсумок, слабкі теми, бейдж, CTA з адмінки. |
| `/admin/marathons` | CRUD, учасники, воронка, CSV. Дозвіл `marathon:manage` (зараз лише роль `admin`). |

Після створення адмінка відкриває редактор цього марафону. Зверху — повне публічне посилання `https://<origin>/marathon/<slug>` (`absoluteSiteUrl` з `src/lib/siteOrigin.ts`) і кнопка «Копіювати». Те саме посилання є в списку на `/admin/marathons`. Чернетка за цим URL не відкривається, доки статус не «Активний».

Форми адмінки (марафон, загадки, дні, матеріали, завдання) не покладаються на бульбашку браузера: порожнє або хибне поле лишає введені значення і показує причину біля поля та списком над кнопкою. Дата старту за замовчуванням — сьогодні за Києвом. Успіх — «Збережено». Кнопка на час запиту показує стан очікування.

Підтвердження пошти — наявний `/verify-email`. Після реєстрації з марафону cookie `marathon_return` веде успішний екран на карту днів.

Google-вхід **немає**. На формі лишається TODO: додати, коли з’явиться OAuth.

Приклад марафону (`math-5`, три загадки, п’ять тем) створює кнопка в адмінці. Схема його сама не сідає, щоб видалення не відроджувало рядок на кожному старті процесу.

## Відкриття дня

День N відкривається для **всіх** учасників одночасно: `start_date + (N-1)` календарних днів о `unlock_hour` у зоні `Europe/Kyiv`. Рахує сервер. Пізній вступ бачить уже відкриті дні.

`pass_threshold` лише ставить позначку «зараховано» і живить серію. Закритий день не пускає ні URL, ні server action.

Серія — підряд зараховані дні **вчасно** (до відкриття наступного). Пропущений день, закритий пізніше, обнуляє серію. Поточний відкритий і ще не зданий день серію не ламає.

## Сповіщення

Лист (Brevo, `src/modules/mail/sendMail.ts`) і Telegram:

- «Відкрито день N» — у вікні 36 годин після відкриття (щоб пізній вступ не отримав пачку за всі минулі дні).
- Нагадування о 19:00 за Києвом, якщо сьогоднішній день не зданий, до відкриття наступного.

Канали обирає учасник на карті: пошта, бот або обидва. Пошта увімкнена за замовчуванням. Бот — після прив’язки.

Ідемпотентність: `marathon_notifications` з ключем `(marathon_id, user_id, day_number, kind, channel)`. Повторний запуск cron не шле дубль. Якщо відправка впала, запис знімається і наступний запуск спробує знову.

Відписка: посилання в листі (`GET /api/marathon/unsubscribe`) вимикає `notify_email`. Повернути можна галочкою в кабінеті.

### Змінні середовища

Не комітити секрети.

| Змінна | Навіщо |
| --- | --- |
| `BREVO_API_KEY`, `MAIL_FROM` | Листи. Без ключа `sendMail` пише в лог. |
| `SESSION_SECRET` | Сесія. Також запасний секрет підпису відписки. |
| `MARATHON_CRON_SECRET` | `Authorization: Bearer …` для cron. Якщо порожній — ендпоінт відповідає 401. |
| `MARATHON_UNSUBSCRIBE_SECRET` | Необов’язково. Інакше береться `SESSION_SECRET`, потім `MARATHON_CRON_SECRET`. |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` | Той самий бот, що для прив’язки акаунта. Без пари кнопка «Прив’язати» показує, що бот вимкнено, а cron пропускає канал Telegram. |
| `TELEGRAM_WEBHOOK_SECRET` | Уже є для `POST /api/telegram/webhook`. |

### Cron на хостингу (nginx, не Vercel)

Раз на 10 хвилин, щоб спіймати 09:00 і 19:00 за Києвом:

```bash
*/10 * * * * curl -fsS -X POST -H "Authorization: Bearer $MARATHON_CRON_SECRET" https://nmt.in.ua/api/marathon/notifications/process
```

Секрет тримати в crontab або в env панелі, не в репозиторії.

### Telegram

Webhook лишається `https://nmt.in.ua/api/telegram/webhook`.

Учасник тисне «Прив’язати Telegram» на карті. Сервер видає одноразовий код на 30 хвилин і веде на `https://t.me/<TELEGRAM_BOT_USERNAME>?start=<код>`. Код починається з `mth_` і не збігається з 43-символьним токеном прив’язки акаунта. `/start` з таким payload пише `telegram_chat_id` і вмикає `notify_bot`.

## Воронка

Зареєстровані (рядки учасників) → пошта підтверджена (`email_verified_at`) → день 1 … день N (`completed_at`) → фініш (`finished_at`, коли здано стільки днів, скільки в марафоні) → перехід (`converted_at` після кліку CTA). Розбивка за `utm_source`. CSV: `GET /api/admin/marathons/[id]/export` (той самий дозвіл).

## Відкриті питання

- Текст і URL фінальної пропозиції ще не вирішені. Адмін задає їх у картці марафону без змін коду. Приклад веде на `/`.
- Google OAuth не підключали.
- Нагадування фіксоване на 19:00 Europe/Kyiv, не налаштовується в адмінці.
- Лідерборд трьох активностей — окрема картка, сюди не входить. Оплата теж.
